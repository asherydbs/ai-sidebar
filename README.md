# AI Sidebar - 对话索引侧边栏

一个为 AI 聊天平台设计的 Chrome 浏览器扩展，自动索引你的对话提示词，提供快速导航和书签功能。

## 功能特性

- **多平台支持**：支持 ChatGPT、Claude、Gemini 等主流 AI 对话平台
- **自动索引**：自动识别并索引对话中的用户提示词
- **快速导航**：点击侧边栏中的提示词即可快速跳转到对应位置
- **书签功能**：支持为重要提示词添加星标书签
- **实时搜索**：支持搜索提示词内容，快速定位
- **智能高亮**：滚动时自动高亮当前视口中的提示词
- **可调节宽度**：拖动侧边栏左侧边缘可调整宽度（240px - 600px）
- **可折叠**：点击侧边栏左侧的箭头按钮可收起/展开侧边栏
- **多语言**：支持中文和英文界面
- **智能主题**：自动跟随AI页面主题，支持手动切换浅色/深色/自动模式

## 安装方法

### 方式一：Chrome 应用商店（暂未上架）

1. 访问 Chrome 网上应用商店
2. 搜索 "AI Conversation Index Sidebar"
3. 点击"添加至 Chrome"

### 方式二：开发者模式安装

1. 下载本项目源码
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹

## 使用方法

### 基本操作

1. **打开侧边栏**：访问支持的 AI 平台网站，侧边栏会自动显示在页面右侧
2. **跳转提示词**：点击侧边栏中的任意提示词，页面会自动滚动到对应位置
3. **添加书签**：点击提示词右侧的星标按钮添加/移除书签
4. **搜索提示词**：在侧边栏顶部的搜索框中输入关键词进行搜索

### 界面控制

- **调整宽度**：将鼠标悬停在侧边栏左侧边缘，当光标变为左右箭头时拖动
- **收起/展开**：点击侧边栏左侧的 `▶` / `◀` 按钮
- **切换语言**：点击浏览器工具栏中的扩展图标，在弹出窗口中选择语言
- **切换主题**：点击侧边栏右上角的 **自动/浅色/深色** 按钮切换主题模式

- 不会收集或上传任何对话内容
- 仅在支持的 AI 网站中运行
